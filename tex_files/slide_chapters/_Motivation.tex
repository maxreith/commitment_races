\begin{frame}{Can AI Agents Make Commitments?}
  \begin{itemize}
    \item AI agents may be able to make credible commitments  
      \parencite{hammond_multi-agent_2025,kokotajlo_commitment_2019}
    \pause
    \vspace{0.5em}
    \item Concern: commitment could be used for extortion:  
    \begin{itemize}
        \item One AI agent commits to an aggressive strategy, forcing another to accommodate
    \end{itemize}

    \vspace{0.5em}
    \item If both agents can commit, there are incentives to do so first

    \vspace{0.5em}
    \item Such a “commitment race” (Kokotajlo 2019) could lead to simultaneous, incompatible commitments—and worse outcomes for both
  \end{itemize}
\end{frame}
